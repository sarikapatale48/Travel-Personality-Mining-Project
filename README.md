# Travel Personality Mining Project

Uses K-Means, Hierarchical Clustering & PCA to predict travel personalities.

### Files

- **app.py** - main python code
- **index2.html** - website structure
- **style.css** - design / css part
- **script.js** - javascript logic
- **background.js** - bridge for live detection
- **content.js** - styling & access
- **manifest.json** - live detection permissions
- **emotion_model.pkl** - real-time model file
- **img1, img2, img3** - UI images

### How to Run
pip install -r requirements.txt
streamlit run app.py
